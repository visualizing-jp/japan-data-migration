# データソース

「日本人はどこへ移り住んできたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

国内の住所変更（市区町村をまたぐ転居）を、**時代・地域（転入超過）・出来事**の3ビューで見せる。
一次ソースは総務省「住民基本台帳人口移動報告」（政府統計コード `00200523`）。
単位は**人**（移動者数・転入超過数）。人口そのものではない。

東京一極集中・地方→都市・バブル／震災／コロナは、三大都市圏の転入超過と都道府県別転入超過で読む。
長期接続のため、国籍は原則**日本人移動者**（コード `61000`）に揃える（2014年以降の「移動者」は外国人を含む）。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代（全国） | 年報 推移表 → 年報（実数）で延長 | `0003404079` + `0003422373` | 指標×年 | 移動者数・県内・県間 |
| 時代（三大都市圏） | 同上 | `0003404102` + `0003422373` | 圏×年 | 転入・転出・転入超過 |
| 地域 | 年報（総数）2019年以前 → 年報（実数） | `0004009738` + `0003422373` | 指標×年×都道府県 | 転入超過・転入・転出 |
| 出来事 | 時代と同じ系列 | 同上 | 注記×年 | 図上の縦線・帯 |

出典表記: 総務省「住民基本台帳人口移動報告」（e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0003404079` — 移動者数等の推移（全国・1954–2019）

- 平成31年・令和元年年報の長期表。軸: 指標(5) × 国籍(2) × 性別(4) × 県内/県間(3) × 全国 × 年(66)
- 採用: `cat01=014`（移動者数）× `cat02=61000`（日本人移動者）× `cat03=001`（総数）× `cat04` 001/002/003
- 年次コードは `YYYY000000`
- 実測: 1954年 移動者数 5,498,318人 / 2019年 4,889,191人（日本人）

### `0003404102` — ３大都市圏の転入・転出・転入超過（1954–2019）

- 軸: 圏(4) × 転入/転出/超過/率(4) × 国籍(2) × 年(66)
- 採用: 東京圏 `002` / 名古屋圏 `003` / 大阪圏 `004` × 転入 `001`・転出 `002`・転入超過 `003` × 日本人 `61000`
- 実測: 東京圏転入超過（日本人）1987年 163,644 / 2011年 62,809 / 2019年 145,576

### `0003422373` — 都道府県・３大都市圏の転入出（2010年～・年報実数）

- 軸: 表章(4) × 性別(3) × 国籍(3) × 地域(74) × 年(16: 2010–2025)
- 採用クエリ: `cdCat01=0`（総数）× `cdCat02=61000`（日本人移動者）
- 表章: `01` 県内移動 / `02` 転入 / `03` 転出 / `04` 転入超過
- 三大都市圏コード: 東京圏 `51000` / 名古屋圏 `52000` / 大阪圏 `53000`
- **接続**: 全国の移動者数 ≈ 県内 + 転入。2019年は `2,835,379 + 2,568,086 = 5,403,465`（移動者・外国人含む）で長期表の移動者側と整合。日本人系列は長期表を2019まで、本表で2020以降を延長

### `0004009738` — 都道府県の転入出（1999–2019・年報総数）

- 軸: 表章(4) × 国籍(2) × 推移(3) × 地域(70) × 年(21)
- 採用: `cdCat01=61000` × `cdCat02=03`（今年）
- 地域ビューの 1999–2009 を本表、2010以降は `0003422373` を優先（定義の連続）

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 市区町村 OD・年齢別詳細 | セル数が大きく、第1版の物語（一極・地方→都市・出来事）に必須ではない |
| 社会・人口統計体系 A510x / #A053x | 住民基本台帳由来だが、theme の統計名に直接寄せるため第1版は年報本体を採用 |
| 外国人移動者のみの系列 | 「日本人はどこへ」の問いに対し、まずは日本人移動者で揃える |
| 月報 | 年次の物語が主。季節性は第2版 |

## 4. 接続・定義ルール

- **日本人移動者**を既定とする。2014年以前は「移動者」と実質同値の期間がある
- 全国の都道府県間移動 ≈ 全国の他都道府県からの転入（年報実数の全国）
- 三大都市圏の転入超過は圏外との純移動。全国の転入超過は国内のみなら概ね0
- 地域の相対色は全国比ではなく**転入超過数そのもの**（発散尺度・0中心）。全国の転入超過は色の基準に使わない

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | people | metrics |
| `geo.json` | metric × year × area | value | metrics, areas |
| （出来事） | UI 注記のみ | — | `src/app/data/annotations.ts` |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 対象は住民票の届け出に基づく国内移動。国外との移動は本ダッシュボードの主系列に含めない
- 2014年以降、外国人住民が「移動者」に含まれる。表示は日本人移動者
- 東京圏＝埼玉・千葉・東京・神奈川。名古屋圏＝岐阜・愛知・三重。大阪圏＝京都・大阪・兵庫・奈良（年報の定義）
- バブル末期・東日本大震災・コロナ禍は図上の出来事注記として明示
